## About the Notes

These are **personal study notes**, not official course materials.

I try to rewrite concepts in my own words and focus on understanding the ideas rather than simply copying lecture content.

Some notes may therefore be:

- simplified
- incomplete
- reorganised in a way that makes more sense to me
- updated later as my understanding improves

---

## Academic Integrity

This repository is intended for:

- lecture notes
- conceptual explanations
- revision material
- personal summaries of what I have learned

I do **not** publish:

- complete problem set solutions
- assessed assignment solutions
- solution code that could be submitted as coursework

The purpose of this repository is to document my learning and understanding, not to provide answers to assessed work.
